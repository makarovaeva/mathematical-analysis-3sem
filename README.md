## 1. Численное вычисление двойных интегралов

**Описание**

В разделе рассматриваются методы приближенного вычисления двойных интегралов
по прямоугольных и треугольным областям. Дальнейшее сопоставление численных
результатов вычислений с аналитическими значениям позволяет исследовать влияние выбранного
подхода моделирования на погрешность вычислений.

**Теория**

<ins>Двойной интеграл и аналитическое вычисление.</ins>
Пусть $D$ — область на плоскости, $x,y$ — координаты её точек,
а $f(x,y)$ — заданная подынтегральная функция. Двойной интеграл

$$
I=\iint_D f(x,y)\,dx\,dy
$$

представляет предел сумм значений функции, умноженных на площади малых частей
области. Здесь $I$ — точное значение интеграла, а $dx\,dy$ обозначает элемент площади.
Для непрерывной функции на прямоугольнике $D=[0,a]\times[0,b]$, где
$a>0$ и $b>0$ — длины сторон, интеграл можно вычислить с помощью повторных интегралов:

$$
I=\int_0^a\left(\int_0^b f(x,y)\,dy\right)dx.
$$

Во внутреннем интеграле $x$ считается постоянным. Полученное выражение
затем интегрируется по $x$. Это аналитический способ вычисления.

<ins>Численные методы: разбиение области на сетку.</ins>
При численном вычислении интеграл заменяется конечной суммой.
Разделить каждую сторону прямоугольника на $n$ равных отрезков,
где $n$ — положительное целое число. Шаги сетки равны
$h_x=a/n$ и $h_y=b/n$. Получаются $n^2$ ячеек площади $h_xh_y$.
Индексы $i$ и $j$ нумеруют отрезки по осям $x$ и $y$ соответственно.
Увеличение $n$ означает уменьшение шагов и измельчение сетки.

<ins>Метод средних прямоугольников.</ins>
В каждой ячейке значение функции заменяется её значением в центре.
Координаты центра ячейки с индексами $i,j$:

$$
x_i^*=(i+\tfrac12)h_x,\qquad y_j^*=(j+\tfrac12)h_y,
\qquad i,j=0,\ldots,n-1.
$$

Звёздочка здесь обозначает координату центра ячейки. Приближение интеграла равно

$$
I_n^{\text{ср}}=h_xh_y\sum_{i=0}^{n-1}\sum_{j=0}^{n-1}f(x_i^*,y_j^*).
$$

Каждое слагаемое — значение функции в центре, умноженное на площадь ячейки;
двойная сумма объединяет вклады всех ячеек. Обозначение $I_n^{\text{ср}}$
соответствует результату метода средних прямоугольников при данном $n$.

<ins>Метод трапеций.</ins>
Вместо центров используются узлы сетки $x_i=ih_x$, $y_j=jh_y$,
где $i,j=0,\ldots,n$. На каждой ячейке берётся среднее арифметическое
значений функции в её четырёх вершинах и умножается на площадь ячейки.
После сложения вкладов получается формула

$$
I_n^{\text{тр}}=h_xh_y\sum_{i=0}^{n}\sum_{j=0}^{n}w_iw_j f(x_i,y_j),
\qquad
w_\ell=\begin{cases}
\tfrac12,&\ell=0\text{ или }\ell=n,\\
1,&1\leq\ell\leq n-1.
\end{cases}
$$

Здесь $I_n^{\text{тр}}$ — приближение методом трапеций;
$w_i,w_j$ — веса по соответствующим координатам, а $\ell$ — общий индекс
для определения этих весов. Произведение $w_iw_j$ равно $1$ во внутренних
узлах, $1/2$ на стороне без углов и $1/4$ в углах прямоугольника.

<ins>Замена переменных для непрямоугольной области.</ins>
Чтобы использовать те же формулы для треугольника, область переводится
в квадрат с новыми координатами $\xi,\eta$. При замене
$x=x(\xi,\eta)$, $y=y(\xi,\eta)$ изменение площади учитывается якобианом:

$$
J=\det\begin{pmatrix}
\dfrac{\partial x}{\partial\xi} & \dfrac{\partial x}{\partial\eta}\\[6pt]
\dfrac{\partial y}{\partial\xi} & \dfrac{\partial y}{\partial\eta}
\end{pmatrix}
=\frac{\partial x}{\partial\xi}\frac{\partial y}{\partial\eta}
-\frac{\partial x}{\partial\eta}\frac{\partial y}{\partial\xi}.
$$

Символ $\partial$ обозначает частную производную, вычисляемую при фиксированном
значении другой переменной. $J$ — определитель матрицы этих производных;
его модуль $|J|$ показывает коэффициент изменения площади:
$dx\,dy=|J|\,d\xi\,d\eta$.
Для треугольника из задания используются $x=a\xi$, $y=b(1-\xi)\eta$,
$0\leq\xi,\eta\leq1$. Новая подынтегральная функция равна

$$
g(\xi,\eta)=f\bigl(a\xi,b(1-\xi)\eta\bigr)|J(\xi,\eta)|.
$$

Квадратуры применяются к функции $g$ на единичном квадрате с шагами
$h_\xi=h_\eta=1/n$. Множитель $|J|$ включается в каждое значение функции.

**Пример**

Рассмотреть $a=b=1$. В первой задаче областью интегрирования является
единичный квадрат, во второй — треугольник с вершинами $(0,0)$, $(1,0)$ и $(0,1)$.

**1. Аналитическое вычисление интеграла по квадрату.**
Для функции $f(x,y)=x^2+xy+y^2$ сначала выполнить интегрирование по $y$,
считая $x$ постоянным:

$$
\int_0^1(x^2+xy+y^2)\,dy
=\left[x^2y+\frac{xy^2}{2}+\frac{y^3}{3}\right]_0^1
=x^2+\frac{x}{2}+\frac13.
$$

Затем интегрировать полученное выражение по $x$:

$$
I_1=\int_0^1\left(x^2+\frac{x}{2}+\frac13\right)dx
=\frac13+\frac14+\frac13=\frac{11}{12}.
$$

**2. Метод средних прямоугольников.**
При $n=1$ имеется одна ячейка площади $1$, её центр — $(1/2,1/2)$.
Поэтому

$$
I_{1,\,n=1}^{\text{ср}}=1\cdot f(\tfrac12,\tfrac12)
=\frac14+\frac14+\frac14=\frac34.
$$

Здесь первый индекс обозначает номер интеграла, а $n$ — число отрезков
по каждой координате. При $n=2$ шаги равны $h_x=h_y=1/2$,
площадь каждой из четырёх ячеек равна $1/4$. Значения функции в центрах:

$$
\begin{array}{c|cccc}
(x,y)&(\tfrac14,\tfrac14)&(\tfrac14,\tfrac34)&(\tfrac34,\tfrac14)&(\tfrac34,\tfrac34)\\[4pt]
\hline
f(x,y)&\tfrac3{16}&\tfrac{13}{16}&\tfrac{13}{16}&\tfrac{27}{16}
\end{array}
$$

Следовательно,

$$
I_{1,\,n=2}^{\text{ср}}
=\frac14\left(\frac3{16}+\frac{13}{16}+\frac{13}{16}+\frac{27}{16}\right)
=\frac78.
$$

Абсолютная ошибка уменьшилась с $|3/4-11/12|=1/6$
до $|7/8-11/12|=1/24$, то есть в четыре раза.

**3. Метод трапеций.**
При $n=1$ используются четыре вершины квадрата. Значения функции равны
$f(0,0)=0$, $f(1,0)=1$, $f(0,1)=1$, $f(1,1)=3$.
Каждая вершина имеет вес $1/4$, поэтому

$$
I_{1,\,n=1}^{\text{тр}}=\frac14(0+1+1+3)=\frac54.
$$

При $n=2$ угловые значения в сумме дают $5$, значения в серединах сторон —
$1/4+1/4+7/4+7/4=4$, а значение в центре равно $3/4$.
С учётом весов и площади ячейки:

$$
I_{1,\,n=2}^{\text{тр}}
=\frac14\left(\frac14\cdot5+\frac12\cdot4+\frac34\right)=1.
$$

Абсолютные ошибки равны $1/3$ и $1/12$ соответственно.

**4. Аналитическое вычисление интеграла по треугольнику.**
Неравенство $x+y\leq1$ даёт пределы $0\leq x\leq1$ и $0\leq y\leq1-x$.
Поэтому

$$
\begin{aligned}
I_2&=\int_0^1\int_0^{1-x}(x+y)\,dy\,dx\\
&=\int_0^1\left(x(1-x)+\frac{(1-x)^2}{2}\right)dx
=\int_0^1\frac{1-x^2}{2}\,dx=\frac13.
\end{aligned}
$$

**5. Замена переменных и численное вычисление.**
Положить $x=\xi$, $y=(1-\xi)\eta$, где $0\leq\xi,\eta\leq1$.
При фиксированном $\xi$ переменная $y$ изменяется от $0$ до $1-\xi$,
то есть новая область соответствует исходному треугольнику.
Частные производные и якобиан равны

$$
\frac{\partial x}{\partial\xi}=1,\quad
\frac{\partial x}{\partial\eta}=0,\quad
\frac{\partial y}{\partial\xi}=-\eta,\quad
\frac{\partial y}{\partial\eta}=1-\xi,\qquad
J=\det\begin{pmatrix}1&0\\-\eta&1-\xi\end{pmatrix}=1-\xi.
$$

На единичном квадрате $J\geq0$, поэтому преобразованный интеграл имеет вид

$$
I_2=\int_0^1\int_0^1g(\xi,\eta)\,d\eta\,d\xi,
\qquad g(\xi,\eta)=\bigl(\xi+(1-\xi)\eta\bigr)(1-\xi).
$$

Численные методы применяются к $g$, то есть значение исходной функции
обязательно умножается на якобиан. При $n=1$ метод средних прямоугольников даёт

$$
I_{2,\,n=1}^{\text{ср}}=g(\tfrac12,\tfrac12)
=\left(\frac12+\frac12\cdot\frac12\right)\frac12=\frac38.
$$

Для метода трапеций $g(0,0)=0$, $g(0,1)=1$, $g(1,0)=g(1,1)=0$,
поэтому $I_{2,\,n=1}^{\text{тр}}=1/4$.
Абсолютные ошибки относительно $I_2=1/3$ равны $1/24$ и $1/12$.
Для остальных сеток расчёт повторяется с новыми узлами и шагами;
результаты оформляются по примеру в требованиях к отчёту
(раздел [«Пример оформления таблицы и графика ошибки»](#пример-оформления-таблицы-и-графика-ошибки)).

## 2. Тройные интегралы и замена координат

**Описание**

В разделе рассматривается вычисление тройных интегралов с помощью замены
координат: поворота декартовых осей, перехода к цилиндрическим и сферическим
координатам. Выбор системы координат позволяет упростить описание области
интегрирования и пределы интегрирования. Сопоставление аналитических и численных
результатов позволяет оценить точность вычислений при уточнении сетки.
Функции реализовать в `solution.py`, эксперименты — в `experiments.py`.

**Теория**

При замене переменных $(x,y,z)=\Psi(u,v,w)$:

$$
\iiint_\Omega f(x,y,z)\,dx\,dy\,dz
=\iiint_{\widetilde\Omega}f\bigl(\Psi(u,v,w)\bigr)
\left|\det\frac{\partial(x,y,z)}{\partial(u,v,w)}\right|du\,dv\,dw.
$$

Якобиан учитывает изменение объёма. Для поворота он равен 1,
для цилиндрических координат — $r$, для сферических — $r^2\sin\varphi$.
В прямоугольной области преобразованных координат для вычисления значения интеграла используется формула
средних прямоугольников в трёх измерениях:

$$
I_n=h_1h_2h_3\sum_{i,j,k=0}^{n-1}g(u_i,v_j,w_k),
$$

где $I_n$ — приближённое значение интеграла; $n$ — число равных отрезков
по каждой из трёх координат; $i,j,k=0,\ldots,n-1$ — индексы ячеек
по координатам $u,v,w$ соответственно.
Если область новых координат имеет вид
$[u_{\min},u_{\max}]\times[v_{\min},v_{\max}]\times[w_{\min},w_{\max}]$,
то шаги сетки равны

$$
h_1=\frac{u_{\max}-u_{\min}}{n},\qquad
h_2=\frac{v_{\max}-v_{\min}}{n},\qquad
h_3=\frac{w_{\max}-w_{\min}}{n}.
$$

Индексы $\min$ и $\max$ обозначают нижнюю и верхнюю границы соответствующего
интервала. Координаты центров ячеек определяются формулами

$$
u_i=u_{\min}+(i+\tfrac12)h_1,\qquad
v_j=v_{\min}+(j+\tfrac12)h_2,\qquad
w_k=w_{\min}+(k+\tfrac12)h_3.
$$

Функция $g(u,v,w)$ — исходная подынтегральная функция, записанная через
новые координаты и умноженная на модуль якобиана замены.
Произведение $h_1h_2h_3$ равно объёму одной ячейки в пространстве новых
координат; сумма объединяет вклады всех $n^3$ ячеек.

### 2.1. Поворот декартовых координат

Найти

$$
I_{\text{п}}=\iiint_{\Omega_{\text{п}}}(x^2+y^2+z^2)\,dx\,dy\,dz,
$$

где область задана неравенствами

$$
0\leq x\cos\alpha+y\sin\alpha\leq a,\quad
0\leq-x\sin\alpha+y\cos\alpha\leq b,\quad 0\leq z\leq c.
$$

Использовать поворот вокруг оси $z$:

$$
u=x\cos\alpha+y\sin\alpha,\quad
v=-x\sin\alpha+y\cos\alpha,\quad w=z.
$$

Обратная замена: $x=u\cos\alpha-v\sin\alpha$,
$y=u\sin\alpha+v\cos\alpha$, $z=w$.
Новая область — $[0,a]\times[0,b]\times[0,c]$.
Это прямоугольный параллелепипед в координатах $(u,v,w)$, поэтому к
преобразованному интегралу можно применить трёхмерную формулу средних
прямоугольников.

### 2.2. Цилиндрические координаты

Найти

$$
I_{\text{ц}}=\iiint_{\Omega_{\text{ц}}}(1+x^2+y^2+z)\,dx\,dy\,dz,
\quad \Omega_{\text{ц}}=\{x^2+y^2\leq R^2,\ y\geq0,\ 0\leq z\leq H\}.
$$

Здесь $R>0$ — радиус основания, $H>0$ — высота. Область представляет
половину сплошного цилиндра, расположенную в полупространстве $y\geq0$.
В цилиндрических координатах $r$ — расстояние до оси $z$, $\theta$ —
угол в плоскости $xy$, отсчитываемый от положительного направления оси $x$,
а координата $z$ сохраняет смысл высоты. Замена имеет вид

$$
x=r\cos\theta,\qquad y=r\sin\theta,\qquad z=z.
$$

Неравенство $x^2+y^2\leq R^2$ даёт $0\leq r\leq R$.
Для выбранной половины цилиндра достаточно $0\leq\theta\leq\pi$,
поскольку на этом промежутке $\sin\theta\geq0$. Высота изменяется от $0$ до $H$.
Таким образом, область новых координат — $[0,R]\times[0,\pi]\times[0,H]$.
Для $r>0$ обратные соотношения имеют вид $r=\sqrt{x^2+y^2}$,
$\theta=\arccos(x/r)$; выбор угла здесь учитывает условие $y\geq0$.
На оси $r=0$ угол не определён, но эта особенность не изменяет значение интеграла.

Матрица частных производных и её определитель равны

$$
J=\det\begin{pmatrix}
\cos\theta&-r\sin\theta&0\\
\sin\theta&r\cos\theta&0\\
0&0&1
\end{pmatrix}=r.
$$

Следовательно, $dx\,dy\,dz=r\,dr\,d\theta\,dz$.
После подстановки $x^2+y^2=r^2$ функция для численной квадратуры равна

$$
g(r,\theta,z)=(1+r^2+z)r.
$$

Множитель $r$ учитывает изменение объёма и включается в каждое слагаемое суммы.

### 2.3. Сферические координаты

Найти

$$
I_{\text{с}}=\iiint_{\Omega_{\text{с}}}z^2\,dx\,dy\,dz,\qquad
\Omega_{\text{с}}=\{x^2+y^2+z^2\leq R^2,\ z\geq0\}.
$$

Область представляет верхнюю половину сплошного шара радиуса $R>0$
с центром в начале координат. В сферических координатах $r$ — расстояние
до начала координат, $\theta$ — угол вокруг оси $z$, а $\varphi$ —
угол между радиус-вектором точки и положительным направлением оси $z$.
Использовать замену

$$
x=r\sin\varphi\cos\theta,\qquad y=r\sin\varphi\sin\theta,\qquad
z=r\cos\varphi.
$$

Расстояние изменяется от $0$ до $R$, угол $\theta$ охватывает полный оборот:
$0\leq\theta\leq2\pi$. Условие $z\geq0$ означает $\cos\varphi\geq0$,
поэтому $0\leq\varphi\leq\pi/2$.
Область новых координат — $[0,R]\times[0,2\pi]\times[0,\pi/2]$
в порядке $(r,\theta,\varphi)$.
Обратно, $r=\sqrt{x^2+y^2+z^2}$, $\varphi=\arccos(z/r)$ при $r>0$;
угол $\theta$ определяется направлением проекции точки на плоскость $xy$
с учётом четверти. В коде для этого используется `np.arctan2(y, x)`,
приведённый к диапазону $[0,2\pi)$. На оси $z$ угол $\theta$ не определён,
а в начале координат не определены оба угла; эти особенности не влияют на интеграл.

Модуль якобиана равен $r^2\sin\varphi$, поэтому

$$
dx\,dy\,dz=r^2\sin\varphi\,dr\,d\theta\,d\varphi.
$$

После подстановки $z^2=r^2\cos^2\varphi$ функция для квадратуры имеет вид

$$
g(r,\theta,\varphi)=r^4\cos^2\varphi\sin\varphi.
$$

Она не зависит от $\theta$, но интегрирование по этой координате всё равно
учитывается: полный оборот даёт множитель $2\pi$.

**Пример**

Принять $a=b=c=R=H=1$ и $\alpha=\pi/4$.
Ниже для каждого интеграла показаны преобразование, аналитическое вычисление
и применение численной формулы при $n=1$. Такая сетка используется только
для пояснения метода; в задании расчёты выполняются при $n=8,16,32,64$.

**1. Поворот декартовых координат.**
При $\alpha=\pi/4$ исходная область задаётся неравенствами

$$
0\leq\frac{x+y}{\sqrt2}\leq1,\qquad
0\leq\frac{-x+y}{\sqrt2}\leq1,\qquad 0\leq z\leq1.
$$

Положить $u=(x+y)/\sqrt2$, $v=(-x+y)/\sqrt2$, $w=z$.
В новых координатах это единичный куб. Обратная замена:

$$
x=\frac{u-v}{\sqrt2},\qquad y=\frac{u+v}{\sqrt2},\qquad z=w.
$$

Её якобиан равен

$$
J=\det\begin{pmatrix}
1/\sqrt2&-1/\sqrt2&0\\
1/\sqrt2&1/\sqrt2&0\\
0&0&1
\end{pmatrix}=\frac12+\frac12=1.
$$

Подынтегральная функция преобразуется следующим образом:

$$
x^2+y^2+z^2=\frac{(u-v)^2+(u+v)^2}{2}+w^2=u^2+v^2+w^2.
$$

Следовательно,

$$
\begin{aligned}
I_{\text{п}}
&=\int_0^1\int_0^1\int_0^1(u^2+v^2+w^2)\,dw\,dv\,du\\
&=\int_0^1\int_0^1\left(u^2+v^2+\frac13\right)dv\,du\\
&=\int_0^1\left(u^2+\frac23\right)du=1.
\end{aligned}
$$

При $n=1$ шаги равны $h_1=h_2=h_3=1$, единственный узел —
$(u,v,w)=(1/2,1/2,1/2)$. Численное значение:

$$
I_{\text{п},\,n=1}=1\cdot1\cdot1
\left(\frac14+\frac14+\frac14\right)=\frac34.
$$

Абсолютная ошибка равна $|3/4-1|=1/4$.
При проверке объёма подынтегральная функция с якобианом равна $1$.
Поэтому объём вычисляется точно уже на одной ячейке: $V=1=abc$.

**2. Цилиндрические координаты.**
Область $x^2+y^2\leq1$, $y\geq0$, $0\leq z\leq1$ — половина
цилиндра единичных радиуса и высоты. После замены
$x=r\cos\theta$, $y=r\sin\theta$ пределы равны
$0\leq r\leq1$, $0\leq\theta\leq\pi$, $0\leq z\leq1$.
Модуль якобиана равен $r$, а функция для квадратуры — $(1+r^2+z)r$.
Сначала интегрировать по высоте:

$$
\int_0^1(1+r^2+z)r\,dz
=r\left[(1+r^2)z+\frac{z^2}{2}\right]_0^1
=\left(\frac32+r^2\right)r.
$$

Затем по радиусу и углу:

$$
\begin{aligned}
I_{\text{ц}}
&=\int_0^\pi\int_0^1\left(\frac32r+r^3\right)dr\,d\theta\\
&=\int_0^\pi\left[\frac34r^2+\frac14r^4\right]_0^1d\theta
=\int_0^\pi1\,d\theta=\pi.
\end{aligned}
$$

При $n=1$ шаги равны $h_r=1$, $h_\theta=\pi$, $h_z=1$,
центр ячейки — $(r,\theta,z)=(1/2,\pi/2,1/2)$.
В этой точке

$$
g=\left(1+\frac14+\frac12\right)\frac12=\frac78,
\qquad I_{\text{ц},\,n=1}=1\cdot\pi\cdot1\cdot\frac78=\frac{7\pi}{8}.
$$

Абсолютная ошибка равна $\pi/8$.
Для проверки объёма требуется интегрировать только якобиан:

$$
V=\int_0^\pi\int_0^1\int_0^1r\,dz\,dr\,d\theta
=\pi\cdot\frac12=\frac\pi2.
$$

На одной ячейке численный результат также равен $\pi\cdot(1/2)=\pi/2$.
Точное вычисление объёма не означает, что основной интеграл вычислен точно:
подынтегральные функции у этих двух задач различаются.

**3. Сферические координаты.**
Область $x^2+y^2+z^2\leq1$, $z\geq0$ — верхняя половина единичного шара.
При замене

$$
x=r\sin\varphi\cos\theta,\qquad
 y=r\sin\varphi\sin\theta,\qquad z=r\cos\varphi
$$

пределы равны $0\leq r\leq1$, $0\leq\theta\leq2\pi$,
$0\leq\varphi\leq\pi/2$. Модуль якобиана равен $r^2\sin\varphi$,
поэтому $z^2|J|=r^4\cos^2\varphi\sin\varphi$.
Переменные разделяются, и интеграл равен произведению трёх одномерных интегралов:

$$
I_{\text{с}}=
\left(\int_0^1r^4\,dr\right)
\left(\int_0^{2\pi}d\theta\right)
\left(\int_0^{\pi/2}\cos^2\varphi\sin\varphi\,d\varphi\right).
$$

Первый множитель равен $[r^5/5]_0^1=1/5$, второй — $2\pi$.
Для третьего множителя:

$$
\int_0^{\pi/2}\cos^2\varphi\sin\varphi\,d\varphi
=\left[-\frac{\cos^3\varphi}{3}\right]_0^{\pi/2}=\frac13.
$$

Следовательно, $I_{\text{с}}=(1/5)\cdot2\pi\cdot(1/3)=2\pi/15$.
При $n=1$ шаги равны $h_r=1$, $h_\theta=2\pi$, $h_\varphi=\pi/2$,
а центр ячейки — $(r,\theta,\varphi)=(1/2,\pi,\pi/4)$.
Численное значение равно

$$
I_{\text{с},\,n=1}
=\pi^2\left(\frac12\right)^4
\cos^2\frac\pi4\sin\frac\pi4
=\frac{\pi^2\sqrt2}{64}\approx0.21809.
$$

Точное значение $2\pi/15\approx0.41888$, абсолютная ошибка — примерно $0.20079$.
Для объёма вместо $z^2|J|$ используется $|J|=r^2\sin\varphi$:

$$
V=\left(\int_0^1r^2\,dr\right)
\left(\int_0^{2\pi}d\theta\right)
\left(\int_0^{\pi/2}\sin\varphi\,d\varphi\right)
=\frac13\cdot2\pi\cdot1=\frac{2\pi}{3}.
$$

При $n=1$ численная квадратура даёт $V_1=\pi^2\sqrt2/8$;
в отличие от предыдущих примеров, объём на этой сетке вычисляется приближённо.

Для каждого интеграла расчёт повторяется на сетках из задания.
На каждой сетке вычисляются шаги, центры ячеек и сумма значений функции
с якобианом. Полученные интегралы и объёмы сравниваются с соответствующими
аналитическими значениями. Таблицы ошибок и графики оформляются по примеру
в требованиях к отчёту, приведенному в конце файла.

## 3. Исследование и оптимизация динамической системы

**Теория**

Пусть некоторый сервис обрабатывает поток запросов. Система характеризуется: длиной очереди
$q(t)\geq0$ и числом реплик $c(t)>0$.

Реплика — отдельный работающий экземпляр сервиса. Поступающие запросы
распределяются между репликами, что позволяет обрабатывать их параллельно.
Число реплик $c$ определяет количество таких экземпляров. Например,
если одна реплика обрабатывает $\mu=100$ запросов в секунду, то $c=10$
реплик имеют суммарную производительность $\mu c=1000$ запросов в секунду.

В данной лабораторной работе $c$ рассматривается как непрерывная величина,
поэтому допускаются дробные значения. Это упрощение модели: $c$ описывает
объём выделенного вычислительного ресурса в единицах производительности
одной реплики.

Параметры: $\lambda$ — интенсивность
притока запросов (запросов/с), $\mu$ — производительность одной реплики
(запросов/с на реплику), $u_0\in(0,1)$ — целевая загрузка,
$k>0$ — агрессивность регулятора (1/с).

$$
\dot q=\lambda-\mu c u,\qquad
\dot c=kc\left(\frac{u}{u_0}-1\right),\qquad u=\frac{q}{1+q}. \tag{1}
$$

Здесь $u$ — загрузка: доля времени, когда ресурс занят, а $\mu cu$ — число
запросов, обрабатываемых в секунду. Регулятор наращивает ресурс, если загрузка
выше целевой, и сокращает, если ниже.

Обозначения: $\rho=\lambda/(\mu c)$ — отношение нагрузки к мощности,
$s=\mu c-\lambda$ — запас мощности, $T$ — средняя задержка обработки запроса.
**Закон Литтла** связывает среднее число запросов в системе,
интенсивность их поступления и среднее время пребывания запроса в системе.
В устойчивом установившемся режиме, когда очередь не растёт неограниченно,
а средние характеристики потока сохраняются во времени, эта связь имеет вид

$$
q=\lambda T,\qquad T=\frac{q}{\lambda}.
$$

Здесь $q$ — среднее число учитываемых запросов, $\lambda>0$ — среднее
число поступающих запросов в секунду, $T$ — среднее время пребывания
одного запроса в рассматриваемой части системы, измеряемое в секундах.
Например, при $\lambda=900$ запросов/с и $q=9$ среднее время равно
$T=9/900=0.01$ с, то есть $10$ мс.

Важно одинаково определить границы учёта: если $q$ обозначает только
ожидающие запросы, то $T$ означает время ожидания; если в $q$ включены
и обрабатываемые запросы, то $T$ включает ожидание и обработку.
В этой работе задержка $T$ определяется для той же совокупности запросов,
которая учитывается величиной $q$. В точке равновесия модели вместо $q$
используется найденное значение $q^*$. Для произвольного переходного процесса
равенство $q(t)=\lambda(t)T(t)$ не следует непосредственно из закона Литтла.

Дополнительные параметры, например стоимость ресурса и штраф за ожидание,
определяются в соответствующих заданиях; их значения приведены в приложении Б.

### 3.1. Равновесие и чувствительность

**Описание**

Подраздел посвящён установившемуся режиму сервиса при фиксированном объёме
ресурса. Чувствительность задержки характеризует влияние изменения трафика,
числа реплик и производительности одной реплики. Линейное приближение
позволяет оценить последствия небольших изменений параметров, а относительные
показатели — сопоставить влияние величин с разными единицами измерения.

**Теория**

Равновесие очереди при фиксированном $c$ означает, что её длина не меняется:
$\dot q=0$. При этом скорость поступления запросов равна скорости их обработки.
Условие $s=\mu c-\lambda>0$ означает положительный запас мощности.
По закону Литтла средняя задержка в равновесии равна $T=q^*/\lambda$,
где $q^*$ — равновесная длина очереди.

Частная производная $T_\lambda=\partial T/\partial\lambda$ характеризует
изменение задержки при изменении трафика и фиксированных $c,\mu$.
Аналогичный смысл имеют $T_c$ и $T_\mu$.
Дифференциал задаёт линейное приближение при малых приращениях:

$$
\Delta T\approx T_\lambda\Delta\lambda+T_c\Delta c+T_\mu\Delta\mu.
$$

Здесь $\Delta T$ — изменение задержки, а $\Delta\lambda,\Delta c,\Delta\mu$
— изменения параметров; производные вычисляются в исходной точке.
**Касательная плоскость.**
График функции $T(\lambda,c)$ является поверхностью в пространстве
с координатами $(\lambda,c,T)$. Касательная плоскость проходит через точку
$(\lambda_0,c_0,T(\lambda_0,c_0))$ и задаёт линейное приближение поверхности
в её окрестности. Её наклоны по двум координатам определяются частными
производными в этой точке. При фиксированном $\mu$ уравнение имеет вид

$$
T_{\text{кас}}=T(\lambda_0,c_0)
+T_\lambda(\lambda_0,c_0)(\lambda-\lambda_0)
+T_c(\lambda_0,c_0)(c-c_0),
$$

где $(\lambda_0,c_0)$ — исходная рабочая точка.
Таким образом, уравнение определяется тремя значениями: задержкой
и двумя частными производными в исходной точке. Подстановка новых
$\lambda,c$ в правую часть даёт линейный прогноз задержки.
Этот прогноз точен в исходной точке, но в общем случае является
приближённым при ненулевых изменениях параметров.

**Производная по направлению.**
Частная производная описывает движение вдоль одной координатной оси,
а производная по направлению — изменение функции при одновременном
изменении координат в заданном соотношении.
Градиент $\operatorname{grad}T=(T_\lambda,T_c)$ объединяет частные производные.
Для ненулевого направления $\ell=(\ell_1,\ell_2)$ производная по направлению равна

$$
D_\ell T=\operatorname{grad}T\cdot\frac{\ell}{\|\ell\|},
\qquad \|\ell\|=\sqrt{\ell_1^2+\ell_2^2}.
$$

Вектор $\ell/\|\ell\|$ имеет единичную длину: нормировка исключает
зависимость результата от длины выбранного вектора направления.
Для $\ell=(\Delta\lambda,\Delta c)$ формула принимает вид

$$
D_\ell T=\frac{T_\lambda\Delta\lambda+T_c\Delta c}
{\sqrt{\Delta\lambda^2+\Delta c^2}}.
$$

Положительное значение означает локальное возрастание задержки,
отрицательное — убывание. При нулевом значении линейная часть изменения
равна нулю; это само по себе не доказывает постоянство функции вдоль всей прямой.
Для проверки постоянства рассматривается функция
$T(\lambda_0+t\ell_1,c_0+t\ell_2)$ при допустимых значениях параметра $t$.
Здесь используются числовые значения координат в зафиксированных единицах;
геометрическое направление градиента зависит от выбора масштаба координат.
Линия уровня — множество точек, в которых задержка имеет одно и то же значение.

**Эластичность.**
Эластичность характеризует чувствительность функции в относительных величинах.
Для положительных $T$ и параметра $x$ она определяется как
$E_x=(x/T)\,\partial T/\partial x$ при фиксированных остальных параметрах.
Если $x$ увеличивается на $1\%$, функция приближённо изменяется на $E_x\%$.
Например, $E_x=2$ соответствует росту примерно на $2\%$,
а $E_x=-2$ — уменьшению примерно на $2\%$.
Знак показывает направление изменения, модуль — силу относительного влияния.
Эластичности безразмерны, поэтому позволяют сравнивать влияние разных параметров.
Эластичности $E_\lambda=(\lambda/T)T_\lambda$ и $E_c=(c/T)T_c$
показывают приближённое относительное изменение задержки в ответ на
относительное изменение соответствующего параметра:

$$
\frac{\Delta T}{T}\approx E_\lambda\frac{\Delta\lambda}{\lambda}
+E_c\frac{\Delta c}{c}.
$$

**Метод множителей Лагранжа.**
Этот метод применяется к поиску экстремума функции при равенстве-ограничении.
Пусть требуется исследовать функцию $F(\alpha,\gamma)$ при условии
$g(\alpha,\gamma)=0$. Если градиент ограничения в искомой точке не равен нулю,
необходимое условие условного экстремума имеет вид
$\operatorname{grad}F=\vartheta\operatorname{grad}g$.
Здесь $\vartheta$ — дополнительная неизвестная, называемая множителем Лагранжа.
Функция Лагранжа $L=F-\vartheta g$ позволяет записать это условие как систему

$$
\frac{\partial L}{\partial\alpha}=0,\qquad
\frac{\partial L}{\partial\gamma}=0,\qquad
\frac{\partial L}{\partial\vartheta}=0.
$$

Последнее уравнение возвращает исходное ограничение. Решения системы
являются кандидатами на экстремум; для выбора максимума сравниваются
значения целевой функции либо проводится дополнительное исследование.

В задаче данного подраздела $\alpha=\Delta\lambda/\lambda$ и
$\gamma=\Delta c/c$ — относительные изменения параметров,
а $\delta>0$ — заданная величина их суммарного отклонения.
Целевая функция и ограничение имеют вид

$$
F(\alpha,\gamma)=E_\lambda\alpha+E_c\gamma,\qquad
 g(\alpha,\gamma)=\alpha^2+\gamma^2-\delta^2=0.
$$

Эластичности здесь вычисляются в исходной точке и считаются постоянными.
Соответствующая система равна

$$
E_\lambda-2\vartheta\alpha=0,\qquad
E_c-2\vartheta\gamma=0,\qquad
\alpha^2+\gamma^2=\delta^2.
$$

Ограничение задаёт окружность, поэтому непрерывная функция $F$ достигает
на ней максимума и минимума. Выбранное максимальное значение описывает
наибольшее увеличение задержки в линейном приближении;
точная задержка определяется отдельно в точке
$(\lambda(1+\alpha),c(1+\gamma))$ при положительном запасе мощности.

**Порядок выполнения**

Аналитическое решение оформить в `report.tex`; программная проверка выполняется в подразделе 3.5.

1. Проверить размерности членов системы (1). Объяснить,
   почему при $\mu c\leq\lambda$ система не может прийти в равновесие.

2. Найти равновесную длину очереди $q^*$ из условия $\dot q=0$ и по закону
   Литтла выразить задержку $T(\lambda,\mu,c)$. Показать, что $T$ зависит
   от параметров только через запас $s$.

3. Найти частные производные $T$ по $\lambda,c,\mu$ и дифференциал $dT$;
   вычислить их в рабочей точке и пояснить смысл. Составить уравнение касательной
   плоскости к поверхности $T=T(\lambda,c)$ в рабочей точке и показать,
   что оно задаёт линейный прогноз задержки.

4. Найти производную $T$ по направлению вектора $(\Delta\lambda,\Delta c)$.
   Найти направление, вдоль которого $T$ не меняется, и доказать, что вдоль него
   $T$ постоянна точно. Записать уравнения линий уровня $T$ и построить их график
   в плоскости $(\lambda,c)$ при фиксированном $\mu$.

5. Найти градиент $T$ в плоскости $(\lambda,c)$. Найти эластичности
   $E_\lambda=(\lambda/T)T_\lambda$, $E_c=(c/T)T_c$ и сделать вывод:
   что сильнее влияет на задержку — рост трафика на 1% или рост ресурса на 1%?

6\*. (Худший сценарий.) Относительные отклонения трафика
   $\alpha=\Delta\lambda/\lambda$ и ресурса $\gamma=\Delta c/c$ связаны
   условием $\alpha^2+\gamma^2=\delta^2$, $\delta=0.02$.
   Методом Лагранжа найти $(\alpha,\gamma)$, при которых линейный прогноз
   $\Delta T/T\approx E_\lambda\alpha+E_c\gamma$ максимален.
   Сравнить прогноз с точным значением $T$ в найденной точке.

- выполненная проверка размерностей уравнений модели, выведенное условие существования
  равновесия $\mu c>\lambda$, формулы и численные значения равновесной
  длины очереди $q^*$ и задержки $T$;

- вычисленные частные производные $T_\lambda,T_c,T_\mu$ и их значения
  в исходной точке, выражение для дифференциала и уравнение касательной
  плоскости с подставленными параметрами варианта;

- выведенная формула производной по направлению и вычисленное её значение для вектора
  $(\Delta\lambda,\Delta c)$ своего варианта, направление нулевого изменения
  задержки и доказательство её постоянства вдоль соответствующей прямой;

- записанные уравнения линий уровня и построенный их график в плоскости $(\lambda,c)$
  при фиксированном $\mu$: несколько положительных значений $T$,
  подписи соответствующих линий и отмеченная исходная рабочая точка;

- вычисленные вектор градиента и значения эластичностей $E_\lambda,E_c$ и вывод
  о том, какой параметр сильнее влияет на задержку при одинаковом малом
  относительном изменении, с пояснением знаков эластичностей.

При выполнении дополнительного пункта со звёздочкой также приводятся
функция Лагранжа, решение системы для $\alpha,\gamma,\vartheta$,
обоснование выбора максимума, новые значения трафика и ресурса,
линейный прогноз задержки и его сравнение с точным значением.

**Пример**

Принять $\mu=100$ запросов/с на реплику, $\lambda=900$ запросов/с и $c=10$ реплик. Тогда $s=100$ запросов/с и $\rho=0.9$.

1. $[\dot q]=[\lambda]=[\mu cu]=$ запросы/с,
   $[\dot c]=$ реплики/с, $[k]=1/\text{с}$; $u$ и $u/u_0$ безразмерны.
   Если $\mu c\leq\lambda$, то из $u<1$ следует
   $\dot q=\lambda-\mu cu>\lambda-\mu c\geq0$: очередь растёт при любом $q$.

2. Из уравнения $\dot q=\lambda-\mu cu$ при $\dot q=0$ получаем
   $u=\lambda/(\mu c)=900/(100\cdot10)=0.9$.
   Подстановка $u=q^*/(1+q^*)$ даёт $q^*=u(1+q^*)$, то есть
   $q^*(1-u)=u$. Далее используется закон Литтла $T=q^*/\lambda$:

   $$
   q^*=\frac{\rho}{1-\rho}=9,\qquad
   T=\frac{q^*}{\lambda}=\frac{1}{\mu c-\lambda}=\frac1s=0.01\text{ с}=10\text{ мс}.
   $$

3. Производные вычисляются для $T=s^{-1}$, где $s=\mu c-\lambda$.
   По правилу дифференцирования сложной функции $T_x=-s^{-2}s_x$.
   Так как $s_\lambda=-1$, $s_c=\mu$, $s_\mu=c$, при $s=100$, $\mu=100$, $c=10$:

   $$
   T_\lambda=\frac1{s^2}=10^{-4},\quad T_c=-\frac\mu{s^2}=-10^{-2},\quad
   T_\mu=-\frac c{s^2}=-10^{-3}.
   $$

   $$
   dT=\frac{d\lambda-\mu\,dc-c\,d\mu}{s^2}.
   $$

   Производные характеризуют изменение задержки в секундах при единичном
   изменении соответствующего параметра.
   В формулу касательной плоскости подставляются $T_0=0.01$ с,
   $T_\lambda=0.0001$, $T_c=-0.01$, $\lambda_0=900$, $c_0=10$:

   $$
   T_{\text{кас}}=0.01+0.0001(\lambda-900)-0.01(c-10)\quad\text{(с)}.
   $$

   Умножение всего выражения на $1000$ переводит секунды в миллисекунды:

   $$
   T_{\text{кас}}=10+0.1(\lambda-900)-10(c-10),\qquad T\approx T_0+dT.
   $$

4. В формулу $D_\ell T=(T_\lambda\Delta\lambda+T_c\Delta c)/\|\ell\|$
   подставляются найденные производные. Для $\ell=(\Delta\lambda,\Delta c)$:

   $$
   \frac{\partial T}{\partial\ell}
   =\frac{\Delta\lambda-\mu\Delta c}{s^2\sqrt{\Delta\lambda^2+\Delta c^2}}=0
   \quad\text{при }\ell\parallel(\mu,1)=(100,1).
   $$

   Нулевое значение получается из равенства числителя нулю:
   $\Delta\lambda-\mu\Delta c=0$. Например, подходит вектор $(100,1)$.
   Это соответствует одной реплике на каждые 100 запросов/с.
   Для заданного в примере изменения $(50,0.3)$ производная равна

   $$
   D_\ell T=\frac{50-100\cdot0.3}{100^2\sqrt{50^2+0.3^2}}
   \approx4.0\cdot10^{-5}.
   $$

   Вдоль прямой $\lambda=900+100t$, $c=10+t$ запас $s=100$ не меняется,
   поэтому $T\equiv10$ мс. Линии уровня — параллельные прямые $\mu c-\lambda=1/T$.

5. Градиент составляется из найденных частных производных:
   $\operatorname{grad}T=(10^{-4},-10^{-2})$.
   В определения эластичностей подставляются $T=0.01$, $\lambda=900$, $c=10$:

   $$
   E_\lambda=\frac{\lambda}{T}T_\lambda
   =\frac{900}{0.01}\cdot10^{-4}=9,\qquad
   E_c=\frac{c}{T}T_c=\frac{10}{0.01}\cdot(-0.01)=-10.
   $$

   Таким образом, $E_\lambda=\lambda/s=9$,
   $E_c=-\mu c/s=-10$. Рост трафика на 1% увеличивает задержку примерно на 9%,
   рост ресурса на 1% уменьшает её примерно на 10%. Ресурс влияет немного сильнее.

6\*. Функция Лагранжа
   $L=E_\lambda\alpha+E_c\gamma-\vartheta(\alpha^2+\gamma^2-\delta^2)$.
   Подстановка $E_\lambda=9$, $E_c=-10$, $\delta=0.02$ в условия
   стационарности даёт

   $$
   9-2\vartheta\alpha=0,\quad -10-2\vartheta\gamma=0,\quad
   \alpha^2+\gamma^2=\delta^2.
   $$

   Из первых двух уравнений $\alpha=9/(2\vartheta)$,
   $\gamma=-10/(2\vartheta)$. Подстановка в третье даёт
   $181/(4\vartheta^2)=\delta^2$, откуда
   $\vartheta=\pm\sqrt{181}/(2\delta)$.
   Положительный знак даёт положительное значение $9\alpha-10\gamma$
   и соответствует максимуму; отрицательный — минимуму.
   Максимум достигается при $\alpha=9\delta/\sqrt{181}\approx0.0134$,
   $\gamma=-10\delta/\sqrt{181}\approx-0.0149$.
   Линейный прогноз получается из $T_{\text{пр}}=T_0(1+E_\lambda\alpha+E_c\gamma)$:

   $$
   T_{\text{пр}}=0.01(1+0.02\sqrt{181})\approx0.01269\text{ с}=12.69\text{ мс}.
   $$

   Для точного расчёта используются $\lambda'=900(1+\alpha)$,
   $c'=10(1+\gamma)$ и $T_{\text{точн}}=1/(100c'-\lambda')$.
   Точное значение при $\lambda\approx912.04$, $c\approx9.851$ составляет
   $13.68$ мс: линейный прогноз занижает задержку.

### 3.2. Высшие производные и пределы прогноза

**Описание**

Подраздел рассматривает точность прогнозирования задержки с помощью
производных разных порядков. Формула Тейлора учитывает нелинейность зависимости
и позволяет сопоставить прогнозы при одинаковом изменении параметров.
Отдельно рассматривается различие между стационарной точкой функции выгоды
и точкой её максимума.

**Теория**

Вторые частные производные характеризуют изменение первых производных.
Для функции двух переменных они образуют матрицу Гессе:

$$
H_T=\begin{pmatrix}T_{\lambda\lambda}&T_{\lambda c}\\
T_{c\lambda}&T_{cc}\end{pmatrix}.
$$

При непрерывных вторых производных смешанные производные равны:
$T_{\lambda c}=T_{c\lambda}$.
Для $d=(\Delta\lambda,\Delta c)^{\mathsf T}$ формула Тейлора второго порядка имеет вид

$$
T(\lambda+\Delta\lambda,c+\Delta c)
\approx T(\lambda,c)+\operatorname{grad}T\cdot d+\tfrac12d^{\mathsf T}H_Td.
$$

Все производные в правой части вычисляются в исходной точке;
$\mathsf T$ обозначает транспонирование. При непрерывных вторых производных
остаток, делённый на $\|d\|^2$, стремится к нулю при $d\to0$.

При изменении только трафика полином Тейлора порядка $m$ равен

$$
P_m(h)=\sum_{j=0}^{m}\frac{1}{j!}
\frac{\partial^jT}{\partial\lambda^j}(\lambda,c)h^j,
$$

где $h$ — приращение трафика, $j$ — номер производной, а $j!$ — факториал.
Слагаемое при $j=0$ равно исходному значению $T$.
Радиус сходимости ряда определяет интервал приращений, на котором
бесконечная сумма сходится; конечный полином остаётся приближением.

В стационарной точке функции $G$ её градиент равен нулю.
Для симметричной матрицы Гессе $H_G$ размера $2\times2$ обозначить
через $\Delta_1$ первый диагональный элемент, а через $\Delta_2$ — определитель.
Если $\Delta_1>0$, $\Delta_2>0$, имеется строгий локальный минимум;
если $\Delta_1<0$, $\Delta_2>0$ — строгий локальный максимум.
При $\Delta_2<0$ матрица неопределённа и точка является седловой:
в одних направлениях функция возрастает, в других убывает.
При $\Delta_2=0$ этот тест не даёт окончательного ответа.

1. Вторые производные получаются повторным дифференцированием
   $T_\lambda=s^{-2}$ и $T_c=-\mu s^{-2}$ при фиксированном $\mu$.
   Например, $\partial(s^{-2})/\partial\lambda=-2s^{-3}(-1)=2s^{-3}$.
   Таким образом, $T_{\lambda\lambda}=2/s^3$, $T_{cc}=2\mu^2/s^3$,
   $T_{\lambda c}=T_{c\lambda}=-2\mu/s^3$.
   Определитель равен $4\mu^2/s^6-4\mu^2/s^6=0$:
   $T$ зависит только от $s$ и вдоль направления $(\mu,1)$ не меняется.

2. База индукции: $n=1$, $T_\lambda=1/s^2$. Так как $s_\lambda=-1$,

   $$
   \frac{\partial}{\partial\lambda}\frac{n!}{s^{n+1}}
   =n!\bigl(-(n+1)\bigr)s^{-(n+2)}(-1)=\frac{(n+1)!}{s^{n+2}}.
   $$

   Ряд Тейлора — геометрическая прогрессия:

   $$
   T(\lambda+h)=\sum_{n=0}^\infty\frac1{n!}\frac{\partial^nT}{\partial\lambda^n}h^n
   =\sum_{n=0}^\infty\frac{h^n}{s^{n+1}}=\frac1{s-h},\qquad |h|<s.
   $$

   Радиус сходимости $R=s=100$ запросов/с.

3. В формулу полинома Тейлора
   $P_m(h)=\sum_{j=0}^{m}h^j/s^{j+1}$ подставляются $s=100$ и $h=s/2=50$.
   Прогнозы первого, второго и третьего порядков отличаются количеством слагаемых:

   $$
   \begin{aligned}
   P_1&=\frac1{100}+\frac{50}{100^2}=0.015\text{ с},\\
   P_2&=P_1+\frac{50^2}{100^3}=0.0175\text{ с},\\
   P_3&=P_2+\frac{50^3}{100^4}=0.01875\text{ с}.
   \end{aligned}
   $$

   Точное значение вычисляется подстановкой нового трафика $\lambda+h$:
   $T_{\text{точн}}=1/(s-h)=1/(100-50)=0.02$ с.
   Абсолютные ошибки $|P_m-T_{\text{точн}}|$ равны
   $0.005$, $0.0025$, $0.00125$ с, то есть $5$, $2.5$, $1.25$ мс.
   Каждый порядок уменьшает ошибку вдвое, так как $h/s=1/2$;
   при $h\to s$ прогноз фиксированного порядка теряет точность.

   $$
   P_1=T_0+T_\lambda\Delta\lambda+T_c\Delta c.
   $$

   в исходной точке, а $\Delta\lambda=50$, $\Delta c=0.3$ — заданные изменения.
   Подстановка даёт

   $$
   P_1=0.01+10^{-4}\cdot50-0.01\cdot0.3=0.012\text{ с}=12\text{ мс}.
   $$

   Прогноз второго порядка имеет вид $P_2=P_1+Q$, где

   $$
   Q=\frac12\left(T_{\lambda\lambda}\Delta\lambda^2
   +2T_{\lambda c}\Delta\lambda\Delta c+T_{cc}\Delta c^2\right).
   $$

   При $s=100$, $\mu=100$ вторые производные равны
   $T_{\lambda\lambda}=2\cdot10^{-6}$, $T_{\lambda c}=-2\cdot10^{-4}$,
   $T_{cc}=0.02$. Поэтому

   $$
   \begin{aligned}
   Q&=\frac12\left(2\cdot10^{-6}\cdot50^2
   +2\cdot(-2\cdot10^{-4})\cdot50\cdot0.3+0.02\cdot0.3^2\right)\\
   &=\frac12(0.005-0.006+0.0018)=0.0004\text{ с}.
   \end{aligned}
   $$

   Таким образом, $P_2=0.012+0.0004=0.0124$ с, то есть $12.4$ мс.
   В точной формуле изменяются оба параметра:

   $$
   T_{\text{точн}}=\frac1{\mu(c+\Delta c)-(\lambda+\Delta\lambda)}
   =\frac1{100\cdot10.3-950}=0.0125\text{ с}.
   $$

   Ошибки первого и второго порядков равны соответственно $0.5$ и $0.1$ мс.

5\*. Для $a=b=1$, $p=0.02$:

   $$
   G_\lambda=p-\frac{b\mu c}{s^2},\qquad G_c=-a+\frac{b\mu\lambda}{s^2}.
   $$

   В стационарной точке $p=b\mu c/s^2$ и $a=b\mu\lambda/s^2$.
   Деление первого равенства на второе даёт $p/a=c/\lambda$, то есть
   $c=p\lambda/a$. Тогда $s=\lambda(\mu p-a)/a$.
   Подстановка этого выражения в $a=b\mu\lambda/s^2$ и сокращение
   на $\lambda>0$ дают следующие формулы (здесь $\mu p-a=100\cdot0.02-1=1$):

   $$
   \lambda^*=\frac{ab\mu}{(\mu p-a)^2}=100,\qquad
   c^*=\frac{b\mu p}{(\mu p-a)^2}=2,\qquad s=100.
   $$

   Вторые производные получаются дифференцированием $G_\lambda$ и $G_c$.
   В них подставляются координаты найденной стационарной точки
   $\lambda^*=100$, $c^*=2$, а не исходные $900$ и $10$:

   $$
   G_{\lambda\lambda}=-\frac{2b\mu c}{s^3}=-4\cdot10^{-4},\quad
   G_{cc}=-\frac{2b\mu^2\lambda}{s^3}=-2,\quad
   G_{\lambda c}=\frac{b\mu(\mu c+\lambda)}{s^3}=0.03.
   $$

   $\Delta_1<0$, $\Delta_2=8\cdot10^{-4}-9\cdot10^{-4}=-10^{-4}<0$:
   стационарная точка — седло. Здесь
   $\Delta_2=G_{\lambda\lambda}G_{cc}-G_{\lambda c}^2$.
   Чтобы исследовать поведение вне этой точки, при постоянном запасе $s$
   подставим $\lambda=\mu c-s$ в функцию выгоды:

   $$
   G=(p\mu-a-b\mu/s)c-ps+b.
   $$

   Вдоль прямых с постоянным запасом $s$
   выгода меняется линейно с наклоном $p\mu-a-b\mu/s$;
   при $s>b\mu/(p\mu-a)=100$ она растёт неограниченно.
   Максимума нет, $G^*=-b\lambda^*/s=-1<0$.
   Поэтому трафик нужно считать заданным и оптимизировать только ресурс (подраздел 3.4).

### 3.3. Динамика регулятора

**Описание**

Здесь рассматривается изменение очереди и ресурса во времени при действующем
регуляторе. Поведение системы вблизи равновесия позволяет установить,
затухают ли небольшие возмущения и сопровождается ли возвращение к равновесию
колебаниями. Параметр $k$ определяет интенсивность реакции регулятора,
а $u_0$ — загрузку, которую он стремится поддерживать.

**Теория**

Пусть $x=(q,c)^{\mathsf T}$ — вектор состояния, а $\dot x=F(x)$ — система
дифференциальных уравнений с правыми частями $F_1,F_2$.
В равновесии $x^*$ выполняется $F(x^*)=0$, то есть обе переменные постоянны.
Для малого отклонения $\varepsilon=x-x^*$ линейное приближение имеет вид
$\dot\varepsilon\approx J\varepsilon$, где

$$
J=\begin{pmatrix}
\partial F_1/\partial q&\partial F_1/\partial c\\
\partial F_2/\partial q&\partial F_2/\partial c
\end{pmatrix}_{x=x^*}
$$

— матрица Якоби, вычисленная в равновесии.

Собственные числа $\nu$ удовлетворяют уравнению $\det(J-\nu E)=0$,
где $E$ — единичная матрица. Для матрицы размера $2\times2$ это уравнение

$$
\nu^2-(\operatorname{tr}J)\nu+\det J=0,
$$

где $\operatorname{tr}J$ — сумма диагональных элементов.
Если вещественные части всех собственных чисел отрицательны,
равновесие локально асимптотически устойчиво: достаточно малые отклонения
затухают со временем. Комплексные числа $\nu=\sigma\pm i\omega$
при $\sigma<0$, $\omega\ne0$ соответствуют затухающим колебаниям в линейном
приближении. Здесь $i^2=-1$, $\sigma$ задаёт скорость затухания,
а $|\omega|$ — угловую частоту.
Порог появления комплексных собственных чисел не является порогом потери устойчивости.

**Порядок выполнения**

   возникают колебания (флаппинг).

   Сделать вывод о поведении системы при $u_0\to1$.

**Пример**

Рассмотреть $\lambda=900$, $\mu=100$.
Из $\dot c=kc(u/u_0-1)=0$ при $k,c>0$ следует $u=u_0$.
Тогда уравнение $q^*/(1+q^*)=u_0$ даёт $q^*=u_0/(1-u_0)$,
а из $\dot q=\lambda-\mu c^*u_0=0$ следует $c^*=\lambda/(\mu u_0)$:

$$
q^*=\frac{u_0}{1-u_0},\qquad c^*=\frac{\lambda}{\mu u_0}.
$$

При $u_0=0.75$ подстановка даёт
$q^*=0.75/(1-0.75)=3$, $c^*=900/(100\cdot0.75)=12$.
Для $F_1=\lambda-\mu cu$ и $F_2=kc(u/u_0-1)$ частные производные равны

$$
\begin{aligned}
(F_1)_q&=-\mu c/(1+q)^2,&(F_1)_c&=-\mu u,\\
(F_2)_q&=kc/[u_0(1+q)^2],&(F_2)_c&=k(u/u_0-1).
\end{aligned}
$$

В них подставляются $u=u_0$, $c=c^*$,
$1/(1+q^*)^2=(1-u_0)^2$ и обозначение $A=\lambda(1-u_0)^2/u_0$.
В результате

$$
J=\begin{pmatrix}-A&-\mu u_0\\kA/(\mu u_0)&0\end{pmatrix},\qquad
\frac{\partial\dot c}{\partial c}=k(u/u_0-1)=0.
$$

При $u_0=0.75$: $A=900(1-0.75)^2/0.75=75$, $\mu u_0=75$, $J=\begin{pmatrix}-75&-75\\k&0\end{pmatrix}$.
Совпадение $kA/(\mu u_0)=k$ — особенность выбранных параметров примера.

$$
\operatorname{tr}J=-A,\quad \det J=kA,\quad
\nu^2+A\nu+kA=0,\quad \nu_{1,2}=\frac{-A\pm\sqrt{A^2-4kA}}2.
$$

Уравнение для собственных чисел получено из $\det(J-\nu E)=0$.
Его дискриминант равен $A^2-4kA$. При $A,k>0$ сумма корней равна $-A<0$,
а произведение равно $kA>0$: вещественные корни отрицательны,
а комплексные имеют вещественную часть $-A/2<0$.
Отрицательный дискриминант означает $A^2-4kA<0$, то есть $k>A/4$.
При $k>0$ вещественные части отрицательны; комплексная пара возникает
при $k>k_*=A/4$. Для $u_0=0.6;0.75;0.9$ соответственно:
$A=240;75;10$ и $k_*=60;18.75;2.5$ (в 1/с).
При $u_0\to1$ имеем $A\to0$: порог колебательного режима уменьшается.

### 3.4. Оптимизация затрат

**Описание**

Подраздел посвящён распределению вычислительного ресурса между двумя
последовательными звеньями сервиса. Увеличение ресурса повышает расходы
на его содержание, но уменьшает очередь и связанные с ней потери.
Оптимальное распределение определяется балансом этих двух составляющих;
отдельно рассматривается случай фиксированного общего ресурса.

**Теория**

Через оба звена проходит один поток интенсивности $\lambda$.
Для звена $i=1,2$ величина $c_i$ обозначает ресурс, $\mu_i$ — производительность
одной реплики, $s_i=\mu_ic_i-\lambda$ — запас мощности,
$T_i=1/s_i$ — равновесную задержку. Здесь $\mu_1=\mu$,
а $\mu_2$ задаётся вариантом. Допустимая область определяется условиями $s_i>0$.
Параметр $a>0$ — стоимость одной реплики в единицу времени,
$b>0$ — штраф за один ожидающий запрос в единицу времени.
По закону Литтла среднее число запросов в звене равно $\lambda T_i$,
поэтому суммарные затраты равны

$$
\Phi(c_1,c_2)=a(c_1+c_2)+b\lambda\left(\frac1{\mu_1c_1-\lambda}
+\frac1{\mu_2c_2-\lambda}\right),\qquad \mu_i c_i>\lambda. \tag{2}
$$

Во внутренней точке минимума дифференцируемой функции её градиент равен нулю.
Положительная определённость матрицы Гессе подтверждает строгий локальный
минимум; выпуклость функции на всей допустимой области позволяет установить
его глобальный характер.

При ограничении $c_1+c_2=N$, где $N$ — общий ресурс, допустимые малые
изменения имеют вид $(\Delta c_1,\Delta c_2)=(t,-t)$.
В условном минимуме производная вдоль этого направления равна нулю.
То же условие выражает метод Лагранжа:
$\operatorname{grad}\Phi=\vartheta\operatorname{grad}(c_1+c_2-N) =\vartheta(1,1)$, где $\vartheta$ — множитель Лагранжа.
Допустимое распределение существует при $N>R_1+R_2$,
где $R_i=\lambda/\mu_i$ — базовая нагрузка звена.

   $\Phi$ по направлению $(1,-1)$ получить условие оптимального распределения
   ресурса и найти $c_1,c_2$ численно. Получить то же условие методом Лагранжа.

<ins>Ожидаемый результат</ins>: выведены формулы оптимального ресурса
$c_1^*,c_2^*$, вычислены их значения и доказан глобальный характер минимума.
Рассчитаны затраты первого звена при исходном и оптимальном ресурсе,
вычислены оптимальная загрузка $u_0^*$ и соответствующий порог $k_*$.
Для ограничения $c_1+c_2=N$ получено условие оптимального распределения
двумя способами: через производную по допустимому направлению
и методом Лагранжа. Найдены численные значения $c_1,c_2$,
проверены ограничение на сумму и положительность запасов мощности.

**Пример**

Для примера принять $\lambda=900$, $\mu=100$, $a=b=1$, $\mu_2=150$, $N=20$.
Если производная по направлению $\ell$ отлична от нуля, то малый шаг вдоль
$\ell$ или $-\ell$ уменьшает $\Phi$, что противоречит минимальности.
Из $\partial\Phi/\partial c_i=a-b\lambda\mu_i/s_i^2=0$ следует

$$
s_i=\sqrt{b\lambda\mu_i/a},\qquad
c_i^*=\frac\lambda{\mu_i}+\sqrt{\frac{b\lambda}{a\mu_i}}
=R_i+\sqrt{b/a}\sqrt{R_i}.
$$

Это правило квадратного корня: ресурс равен базовой нагрузке плюс запас,
пропорциональный $\sqrt{R_i}$.
Для первого звена $R_1=900/100=9$, для второго $R_2=900/150=6$.
При $a=b=1$ получаем $c_1^*=9+\sqrt9=12$,
$c_2^*=6+\sqrt6\approx8.45$.

$$
\Phi_{c_ic_i}=\frac{2b\lambda\mu_i^2}{s_i^3}>0,\qquad \Phi_{c_1c_2}=0.
$$

Матрица вторых производных положительно определена во всей области,
функция выпукла, минимум глобальный.
Затраты одного звена вычисляются по формуле
$\Phi_1(c_1)=ac_1+b\lambda/(\mu_1c_1-\lambda)$:

$$
\Phi_1(12)=12+\frac{900}{100\cdot12-900}=15,\qquad
\Phi_1(10)=10+\frac{900}{100\cdot10-900}=19.
$$

Оптимальная загрузка $u_0^*=\lambda/(\mu_1c_1^*)=900/(100\cdot12)=0.75$.
Подстановка её в формулу порога даёт
$k_*=\lambda(1-u_0^*)^2/(4u_0^*)=900\cdot0.25^2/(4\cdot0.75)=18.75$ 1/с.
При ограничении ресурса

$$
\Phi_{c_1}=\Phi_{c_2}\quad\Longleftrightarrow\quad
\frac{\mu_1}{s_1^2}=\frac{\mu_2}{s_2^2}.
$$

Предельная польза ресурса в звеньях одинакова.
Из ограничения $c_2=20-c_1$. Подстановка в условие равенства производных даёт

$$
\frac{100}{(100c_1-900)^2}
=\frac{150}{(150(20-c_1)-900)^2},\qquad 9<c_1<14.
$$

Этот интервал следует из положительности обоих запасов мощности.
На нём знаменатели положительны, поэтому можно извлечь квадратный корень:
$(c_1-9)/(c_2-6)=\sqrt{R_1/R_2}=\sqrt{9/6}$.
Общий запас ресурса равен $20-9-6=5$, откуда

$$
c_1=9+\frac{5\sqrt9}{\sqrt9+\sqrt6}\approx11.75255,\qquad
c_2=20-c_1\approx8.24745.
$$

Таким образом, $c_1\approx11.75$, $c_2\approx8.25$;
без ограничения $c_1^*+c_2^*\approx20.45>N$.
Метод Лагранжа: $\operatorname{grad}\Phi=\vartheta(1,1)$ даёт то же условие;
Множитель вычисляется по формуле
$\vartheta=\Phi_{c_1}=1-900\cdot100/(100c_1-900)^2\approx-0.19$.
Он равен производной минимальных затрат по $N$:
при малом изменении ресурса $\Delta N$ изменение оптимальных затрат
приближённо равно $\vartheta\Delta N$.

### 3.5. Численная проверка

**Описание**

Численные эксперименты сопоставляют аналитические выводы с результатами
вычислений на компьютере. Рассматриваются приближённые производные,
траектории очереди и ресурса, а также поиск оптимального распределения ресурса.
Выбор шага влияет как на точность результата, так и на устойчивость алгоритма.

**Теория**

Для функции $f(x)$ нескольких переменных приближения частной производной
по координате $x_i$ имеют вид

$$
D_i^+f(x)=\frac{f(x+he_i)-f(x)}{h},\qquad
D_i^0f(x)=\frac{f(x+he_i)-f(x-he_i)}{2h}.
$$

Здесь $h>0$ — шаг приращения, $e_i$ — вектор с единицей на позиции $i$
и нулями на остальных позициях. Первая формула — односторонняя разность,
вторая — центральная. При достаточной гладкости ошибки аппроксимации
имеют порядки $h$ и $h^2$ соответственно. Слишком малый шаг усиливает
влияние округления при вычитании близких чисел, поэтому уменьшение $h$
не всегда улучшает результат.

Метод Эйлера приближает решение $\dot x=F(x)$ последовательностью

$$
x_{n+1}=x_n+\Delta t\,F(x_n),\qquad t_n=n\Delta t,
$$

где $x_n$ — численное состояние в момент $t_n$, $n$ — номер временного
шага, $\Delta t>0$ — его длительность. Для линейного возмущения,
соответствующего собственному числу $\nu$, множитель за один шаг равен
$1+\Delta t\,\nu$. Затухание требует $|1+\Delta t\,\nu|<1$
для всех собственных чисел. Это условие относится к линейному приближению
вблизи равновесия и само по себе не гарантирует допустимость всей траектории.

Градиентный спуск задаёт последовательность
$c^{(n+1)}=c^{(n)}-\eta_n\operatorname{grad}\Phi(c^{(n)})$,
где $c^{(n)}=(c_1^{(n)},c_2^{(n)})$ — текущее распределение ресурса,
а $\eta_n>0$ — шаг оптимизации. Направление антиградиента уменьшает функцию
при достаточно малом шаге, если градиент не равен нулю.
Чрезмерный шаг может увеличить затраты или вывести точку из допустимой области.
Малое изменение точки между итерациями не всегда означает близость к минимуму:
оно может быть следствием слишком малого шага.

**Порядок выполнения**

   (односторонние и центральные разности). Построить в логарифмическом масштабе
   зависимость ошибки $\partial T/\partial\lambda$ от шага $h$, найти оптимальный
   шаг для обеих схем и объяснить, почему ошибка не убывает неограниченно.

  на фоне линий уровня и сравнение с аналитическим минимумом.

Для экспериментов указаны шаги, длительность, допуски и критерии остановки;
код приложен к отчёту.

**Пример**

Для численных иллюстраций принять $\lambda=900$, $\mu=100$, $c=10$, $a=b=1$ и $\mu_2=150$.

```python
import numpy as np

def partial(f, x, i, h, central=True):
    e = np.zeros_like(x, dtype=float)
    e[i] = h
    if central:
        return (f(x + e) - f(x - e)) / (2 * h)
    return (f(x + e) - f(x)) / h
```

В функции `partial` аргумент `x` — массив координат,
`i` — индекс изменяемой координаты (нумерация с нуля),
`h` — шаг разности. Вектор `e` содержит $h$ на позиции $i$;
остальные его координаты равны нулю. Поэтому `f(x + e)` означает
вычисление функции при изменении только выбранного параметра.
Для производной по трафику можно использовать

```python
def delay(x):
    return 1.0 / (100.0 * x[1] - x[0])

point = np.array([900.0, 10.0])
estimate = partial(delay, point, 0, 1.0, central=True)
exact = 1.0 / (100.0 * point[1] - point[0])**2
error = abs(estimate - exact)
```

Здесь $h=1$ выбран для наглядной подстановки. Центральная разность равна

$$
D^0_\lambda T
=\frac{T(901,10)-T(899,10)}{2}
=\frac{1/99-1/101}{2}=\frac1{9999}.
$$

Аналитическая производная равна $1/100^2=10^{-4}$,
поэтому абсолютная ошибка составляет примерно $1.0001\cdot10^{-8}$.
В эксперименте этот расчёт повторяется для разных $h$.
Ошибка складывается из остатка Тейлора (растёт с $h$) и ошибки округления
(растёт как $\varepsilon/h$, $\varepsilon\approx2\cdot10^{-16}$).
Оптимальные шаги имеют порядок $s\sqrt\varepsilon$ и $s\varepsilon^{1/3}$;
для примера приблизительно $1.4\cdot10^{-6}$ и $5\cdot10^{-4}$.

Подстановка $s=100$ и $\varepsilon=2\cdot10^{-16}$ даёт
$100\sqrt{2\cdot10^{-16}}\approx1.4\cdot10^{-6}$ и
$100(2\cdot10^{-16})^{1/3}\approx5.8\cdot10^{-4}$.
Это оценки масштаба шага, а не точные положения минимумов ошибки.

Для вещественного $\nu<0$ условие устойчивости равносильно
$\Delta t<2/|\nu|$. При $u_0=0.75$, $k=10$ быстрое собственное число
$\nu\approx-63.12$, поэтому $\Delta t<0.0317$ с;
это получается подстановкой в
$\nu_{1,2}=(-75\pm\sqrt{75^2-4\cdot10\cdot75})/2$.
Для второго собственного числа $\nu\approx-11.88$ ограничение слабее,
поэтому определяющим является $2/63.12\approx0.0317$.
При $\Delta t=0.030$ множитель быстрой моды равен примерно $-0.8936$,
его модуль меньше единицы; при $\Delta t=0.032$ множитель равен $-1.0198$,
его модуль больше единицы. Так объясняется потеря устойчивости линейного приближения.

Один шаг самого симулятора вычисляется по формулам

$$
\begin{aligned}
u_n&=q_n/(1+q_n),\\
q_{n+1}&=q_n+\Delta t(\lambda-\mu c_nu_n),\\
c_{n+1}&=c_n+\Delta t\,kc_n(u_n/u_0-1).
\end{aligned}
$$

Обе новые координаты используют старые $q_n,c_n$.
Например, при $q_0=3.1$, $c_0=12$, $u_0=0.75$, $k=10$, $\Delta t=0.001$
получается $u_0^{\text{сост}}=3.1/4.1\approx0.756098$,
$q_1\approx3.092683$, $c_1\approx12.000976$.
Обозначение $u_0^{\text{сост}}$ здесь означает загрузку начального состояния,
а не заданную целевую загрузку $u_0=0.75$.

В исходном примере колебания фиксировались по выходу $c(t)$ за равновесное
значение $c^*$ с допуском $10^{-6}$ от начального отклонения.
Получены пороги $63;19.7;2.6$ против $k_*=60;18.75;2.5$.
Эти значения получены перебором $k$ и проверкой численной траектории
при каждом значении. Из одних аналитических формул числа $63;19.7;2.6$
не следуют: результат зависит от начальных условий, шага, длительности
и допуска обнаружения. Вблизи $k_*$ колебания очень малы.
Одно пересечение уровня $c^*$ не доказывает наличие колебаний;
для проверки результата необходимо анализировать повторные изменения
направления отклонения и устойчивость наблюдения при уменьшении временного шага.

Для примера градиентного спуска используется формула

$$
\Phi_{c_i}=a-\frac{b\lambda\mu_i}{(\mu_ic_i-\lambda)^2}.
$$

В начальной точке $(10,10)$ получаем

$$
\Phi_{c_1}=1-\frac{900\cdot100}{(100\cdot10-900)^2}=-8,
\quad
\Phi_{c_2}=1-\frac{900\cdot150}{(150\cdot10-900)^2}=0.625.
$$

При шаге $\eta_0=1$ первая новая точка равна
$(10,10)-1\cdot(-8,0.625)=(18,9.375)$.
При численном градиенте производные оцениваются функцией `partial`,
но формула обновления точки остаётся той же.
После каждого шага проверяется допустимость $\mu_ic_i>\lambda$;
при её нарушении шаг уменьшается.

При численном градиенте, остановке по $\|\Delta c\|<10^{-8}$ и $\mu_2=150$
в исходном примере шаг $\eta_n=1$ даёт 27 итераций,
$\eta_n=2\cdot0.97^n$ — 22 итерации. Получена точка
$(12.000,8.449)$, $\Phi=25.899$.
Значение функции получено подстановкой найденной точки в  (2):

$$
\Phi\approx12+8.44949+
\frac{900}{100\cdot12-900}+\frac{900}{150\cdot8.44949-900}
\approx25.89898.
$$

Число итераций зависит, в частности, от шага численного дифференцирования;
приведённые числа не заменяют собственный расчёт.

### 3.6. Настройка в реалистичных условиях

**Описание**

В этом подразделе рассматривается работа сервиса при изменяющейся нагрузке
и задержке реакции регулятора. Суточные колебания и кратковременный всплеск
трафика нарушают условия постоянного равновесия, поэтому качество настроек
оценивается по затратам за весь период моделирования.

**Теория**

При переменной интенсивности $\lambda(t)$ очередь и ресурс зависят от всей
предшествующей траектории. Задержка $\tau\geq0$ означает, что регулятор
использует информацию о состоянии в более ранний момент $t-\tau$.
Конкретный вид уравнения с задержкой определяет, какие величины запаздывают.
При $0\leq t<\tau$ для вычисления запаздывающих значений необходима история
состояния на интервале $[-\tau,0]$.

Мгновенные затраты равны $L(t)=ac(t)+bq(t)$, где $a,b$ — коэффициенты
стоимости ресурса и ожидания. Их среднее за период моделирования равно

$$
\overline\Phi(u_0,k)=\frac1{T_{\mathrm{sim}}}
\int_0^{T_{\mathrm{sim}}}L(t)\,dt,
$$

где $T_{\mathrm{sim}}>0$ — длительность моделирования,
$u_0\in(0,1)$ и $k>0$ — настраиваемые параметры регулятора.
Зависимость затрат от этих параметров определяется через решение
динамической системы, поэтому вычисление одного значения целевой функции
требует отдельного прогона симулятора.

Численный градиент оценивает изменение средних затрат при небольших
изменениях $u_0$ и $k$. Сопоставимость таких оценок предполагает одинаковые
трафик, начальные условия, историю задержки и настройки численного метода.
В отличие от стационарной задачи, выпуклость этой целевой функции заранее
не установлена, поэтому градиентный спуск не гарантирует глобального минимума.
Порог $k_*$ без задержки характеризует появление колебаний в исходной модели,
а не оптимальное значение $k$ для переменного трафика.

**Порядок выполнения**

Продолжить работу с симулятором из подраздела 3.5 в `solution.py` и `experiments.py`.

1. Добавить в симулятор переменный трафик $\lambda(t)$
   (суточная синусоида и резкий всплеск) и задержку $\tau$ реакции регулятора.

2. Вычислить средние затраты за сутки модельного времени

   $$
   \overline\Phi(u_0,k)=\frac1{T_{\mathrm{sim}}}
   \int_0^{T_{\mathrm{sim}}}(ac(t)+bq(t))\,dt.
   $$

3. Найти минимум $\overline\Phi$ градиентным спуском с численным градиентом,
   начав с $u_0^*$ и $k_*$ из заданий 3.3–3.4. Построить линии уровня
   $\overline\Phi$ на плоскости $(u_0,k)$ и траекторию спуска.

4. Сравнить найденные настройки с аналитическими и ответить на сквозной вопрос работы.

значение задержки $\tau$, уравнение регулятора с задержкой,
начальная история и параметры численного моделирования.

**Пример**

Ниже приведён возможный способ задания эксперимента; он не является
единственным обязательным выбором трафика и задержки для всех вариантов.
Для демонстрационных параметров $\lambda_0=900$, $\mu=100$, $a=b=1$
начальные настройки из подраздела 3.4 равны $u_0=0.75$, $k=18.75$.
Рассмотреть период $P=T_{\mathrm{sim}}=86400$ с и трафик

$$
\lambda(t)=900\left(1+0.2\sin\frac{2\pi t}{86400}
+0.5\,\mathbf1_{[43200,43800]}(t)\right).
$$

Здесь $0.2$ — относительная амплитуда суточного колебания,
а $\mathbf1_{[43200,43800]}(t)$ равна $1$ внутри указанного интервала
и $0$ вне его. Добавка $0.5\cdot900$ описывает всплеск длительностью $600$ с.
Например, при $t=0$ поток равен $900$ запросов/с, а при $t=43200$ — $1350$ запросов/с.

Один из способов учёта задержки $\tau$ состоит в использовании
прошлой загрузки только в уравнении регулятора:

$$
\dot q(t)=\lambda(t)-\mu c(t)u(t),\qquad
\dot c(t)=kc(t)\left(\frac{u(t-\tau)}{u_0}-1\right).
$$

Например, при $\tau=0.01$ с история может быть постоянной:
$q(t)=3$, $c(t)=12$ для $-\tau\leq t\leq0$.
Это равновесие для исходного постоянного потока: $3/(1+3)=0.75$,
$900/(100\cdot0.75)=12$.
При $\tau=m\Delta t$, где $m$ — целое число, запаздывающая загрузка
берётся из сохранённого состояния с индексом $n-m$;
при отрицательном индексе используется заданная история.
Если отношение $\tau/\Delta t$ нецелое, способ интерполяции указывается отдельно.

После симуляции доступны $q_n,c_n$ в моменты $t_n=n\Delta t$,
$n=0,\ldots,M$, где $M\Delta t=T_{\mathrm{sim}}$.
Для каждого узла вычисляется $L_n=ac_n+bq_n$.
Например, в начальной точке $L_0=1\cdot12+1\cdot3=15$.
Формула трапеций даёт средние затраты

$$
\overline\Phi\approx\frac{\Delta t}{T_{\mathrm{sim}}}
\left(\frac{L_0}{2}+\sum_{n=1}^{M-1}L_n+\frac{L_M}{2}\right).
$$

Это численное приближение интеграла из условия, а не среднее только
начального и конечного значений. Для постоянного $L_n=15$ формула даёт $15$.

Численный градиент по настройкам вычисляется отдельными прогонами:

$$
\begin{aligned}
\frac{\partial\overline\Phi}{\partial u_0}
&\approx\frac{\overline\Phi(u_0+\varepsilon_u,k)
-\overline\Phi(u_0-\varepsilon_u,k)}{2\varepsilon_u},\\
\frac{\partial\overline\Phi}{\partial k}
&\approx\frac{\overline\Phi(u_0,k+\varepsilon_k)
-\overline\Phi(u_0,k-\varepsilon_k)}{2\varepsilon_k}.
\end{aligned}
$$

Здесь $\varepsilon_u,\varepsilon_k>0$ — шаги изменения параметров.
Во всех прогонах сохраняются одинаковые трафик, начальная история
и временная сетка. Вычисленные компоненты подставляются в формулу
$\boldsymbol\beta^{(j+1)}=\boldsymbol\beta^{(j)}-\eta_j \operatorname{grad}\overline\Phi$, где
$\boldsymbol\beta=(u_0,k)$, а $j$ — номер итерации оптимизации.
Пробные и новые настройки должны удовлетворять $0<u_0<1$, $k>0$.
При недопустимой или неустойчивой численной траектории соответствующая
оценка затрат не используется как корректное значение целевой функции.

Численные значения итоговых затрат и настроек определяются выполнением
этих прогонов. Их нельзя получить простой подстановкой в стационарные
формулы: $u_0^*$ служит исходной настройкой, а $k_*$ — порогом колебаний
модели без задержки, а не доказанным минимумом затрат.
Устойчивость и точность выбранного временного шага проверяются отдельно;
значение шага, пригодное для системы без задержки, не переносится автоматически
на систему с задержкой.

### Оценка точности

Для скалярной величины абсолютная и относительная ошибки определяются формулами

$$
\Delta=|\widehat z-z|,\qquad \delta=\frac{\Delta}{|z|},\quad z\ne0,
$$

где $z$ — аналитическое значение, $\widehat z$ — программное приближение
той же величины, $\Delta$ — абсолютная ошибка, а $\delta$ — относительная.
Вертикальные черты обозначают модуль числа.
Абсолютная ошибка имеет те же единицы, что и сравниваемая величина;
относительная ошибка безразмерна. Для представления в процентах
значение $\delta$ умножается на $100\%$.
При $z=0$ относительная ошибка не определяется и указывается только абсолютная.
Ошибки вычисляются до округления результатов. Точность округления
в таблицах указывается явно.

Если сравнивается вектор или матрица, удобно использовать максимальное
по модулю расхождение элементов:

$$
\Delta=\max_{\ell}|\widehat z_\ell-z_\ell|,\qquad
\delta=\frac{\Delta}{\max_{\ell}|z_\ell|}.
$$

Здесь $\ell$ нумерует сравниваемые элементы в одинаковом порядке;
$z_\ell$ и $\widehat z_\ell$ — аналитическое и программное значения
соответствующего элемента. Для матрицы максимум берётся по всем её элементам.
Относительная ошибка определяется, если хотя бы один аналитический элемент
ненулевой. Такой способ сравнения применяется к однородным величинам
в одинаковых единицах; например, очередь и ресурс сравниваются отдельно.

Для интеграла обозначить точное аналитическое значение через $I$,
а численное значение на сетке с $n$ отрезками по каждой координате — через $I_n$.
Тогда

$$
\Delta_n=|I_n-I|,\qquad \delta_n=\frac{\Delta_n}{|I|},\quad I\ne0.
$$

Индекс $n$ у ошибок указывает, на какой сетке получен результат.
Для двойного интеграла по прямоугольнику шаги равны
$h_x=a/n$, $h_y=b/n$, где $a,b$ — длины сторон, а индексы $x,y$
обозначают координатные направления. На горизонтальной оси графика
используется $h=\max(h_x,h_y)$ — больший из двух шагов.
После перехода к единичному квадрату оба шага равны $h=1/n$.
Для тройных интегралов используется нормированный шаг $h=1/n$,
соответствующий разбиению каждого координатного интервала на $n$ равных частей.
На вертикальной оси откладывается абсолютная ошибка $\Delta_n$.

Для достаточно гладких функций методы средних прямоугольников и трапеций
обычно имеют второй порядок точности: при пропорциональном уточнении сетки
ведущая составляющая ошибки пропорциональна $h^2$.
Поэтому уменьшение шага вдвое обычно уменьшает ошибку примерно в четыре раза.
Точное совпадение и влияние округления рассматриваются отдельно.
Пример таблицы, графика и кода построения приведён далее
(раздел [«Пример оформления таблицы и графика ошибки»](#пример-оформления-таблицы-и-графика-ошибки)).

I=\int_0^1\int_0^1(x^2+xy+y^2)\,dy\,dx=\frac{11}{12}.

Ниже приведены результаты метода средних прямоугольников. Поскольку область

В таблице $n$ — число отрезков по каждой координате, $h$ — шаг сетки,

| $n$ | $h$ | $I_n$ | $\Delta_n$ | $\delta_n$ |
|:---:|:---:|:---:|:---:|:---:|
| 4 | 0.25 | 0.906250000 | $1.041667\cdot10^{-2}$ | $1.136364\cdot10^{-2}$ |
| 8 | 0.125 | 0.914062500 | $2.604167\cdot10^{-3}$ | $2.840909\cdot10^{-3}$ |

Значения округлены только при оформлении таблицы. Ошибки вычислены

Обе оси имеют логарифмическую шкалу: одинаковые расстояния соответствуют
одинаковому изменению величины в несколько раз. Сетка уточняется при движении
влево, к меньшим значениям $h$. В этом примере $\Delta_n=h^2/6$,
поэтому при уменьшении шага вдвое ошибка уменьшается в четыре раза.
В отчёте после каждого графика требуется дать такую интерпретацию результата.

**Пример кода построения.**
Код воспроизводит приведённые численные результаты и сохраняет график
в текущей рабочей папке. Для своего варианта следует использовать собственные
результаты квадратур и соответствующее аналитическое значение.

```python
import numpy as np
import matplotlib.pyplot as plt

n_values = np.array([4, 8, 16, 32, 64])
h_values = 1.0 / n_values
exact = 11.0 / 12.0
results = []
for n in n_values:
    nodes = (np.arange(n) + 0.5) / n
    x, y = np.meshgrid(nodes, nodes, indexing="ij")
    results.append(np.sum(x**2 + x*y + y**2) / n**2)

errors = np.abs(np.array(results) - exact)
fig, ax = plt.subplots(figsize=(6.6, 3.5), layout="constrained")
mask = errors > 0
ax.loglog(h_values[mask], errors[mask], "o-", label=r"$\Delta_n$")
ax.set_xlabel(r"$h$")
ax.set_ylabel(r"$\Delta_n = |I_n - I|$")
ax.grid(True, which="both", alpha=0.35)
ax.legend()
fig.savefig("error_convergence.pdf")
plt.show()
```

В коде `n_values` содержит числа разбиений, `h_values` —
соответствующие шаги, `exact` — аналитическое значение интеграла,
`results` — численные приближения, `errors` — абсолютные ошибки.
Массив `nodes` содержит координаты центров отрезков,
а `x` и `y` — таблицы координат центров ячеек,
сформированные функцией `np.meshgrid`.
Объект `fig` представляет рисунок, `ax` — область построения графика.
Функция `loglog` задаёт логарифмический масштаб обеих осей.
Маска `errors > 0` исключает нулевые ошибки, для которых логарифм
не определён; сами нулевые значения следует сохранить в таблице и пояснить.
Для двух методов можно добавить второй вызов `ax.loglog` с его
результатами и отдельной подписью в легенде.

Для тройных интегралов аналогичный график удобно строить по шагу
$h=1/n$ нормированных координат, то есть после приведения каждого интервала
новых переменных к $[0,1]$. Тогда одному $n$ соответствует $n^3$ ячеек.
Такой выбор не смешивает линейные и угловые шаги и должен быть указан
в подписи или тексте отчёта.
